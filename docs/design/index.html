Static HTML review mocks for siorie, a small reading tracker. Mobile-only, light-only, one 430px column. The React app is not changed yet — this is the review before implementation.

At a glance

What this direction changes

Groups stay independent cards

One white card per group, 12px gap, 12px radius. The list is not one enclosing box.

Items share a flat white band

One white band, no radius or side border. 1px top/bottom rules plus row dividers; the white fill keeps the rows legible. Titles stay on one line and truncate before vol..

Group detail gets a 3-tier head

Group + Edit on top, the group title in the middle, Items + Add item below. Item detail mirrors it with Item + Edit and a wrapping title.

One blue, used sparingly

#3148F6 is the primary action and focus colour. #1C4B8F is the quieter hover / sub-accent. Everything else is grey or charcoal.

01 · Colour

Palette

The five specified colours are the brand palette. Muted text, borders, error, and the scrim are derived functional roles, not new brand colours. No gradients, no extra accent hue.

White cards on #E9E9E9 are only 1.21:1, so no card may rely on fill alone: every card, form, and input keeps a 1px outline. The flat item list uses --line-strong at its ends so the list has a readable edge without becoming a box.

02 · Type

Typography

The existing OS font stack is kept. No web font is downloaded, so the rounded-gothic rendering remains best-effort per platform. Hierarchy comes from size, weight, and spacing, not from a second family.

06 · Rules

Rules for the implementation

The visual source of truth is this folder. If the HTML and a later prompt disagree, the HTML wins for spacing, colour, and hierarchy; the routes, API contract, and copy stay as they are.

Use
  • One blue primary action per screen; #3148F6.
  • #1C4B8F for hover, pressed, eyebrows, and secondary emphasis.
  • White cards on #E9E9E9, always with a 1px outline.
  • The flat item list: one white band, no radius or side border, top/bottom + row rules.
  • Item titles are one line; truncate with an ellipsis before the fixed vol. column.
  • 24px page padding, 20px card padding, 12px group-card gap.
  • English UI copy; Japanese is user content only.
  • Keep the Google-rendered sign-in button as Google draws it.
Avoid
  • Gradients, glassmorphism, or decorative background shapes.
  • Card shadows; shadows are for overlays only.
  • Pill buttons or a second accent hue.
  • An enclosing rounded box around the item list.
  • Wrapping item titles, or letting them collide with vol..
  • A desktop multi-column layout; the app stays 430px.
  • Inline +1 on item rows; the +1 stays on item detail.
  • A web font or a dark mode.
