siorie — style guide

Moss × rounded gothic. Mobile-only, light-only, single column, English copy only. Golden ratio drives the type scale and the vertical rhythm. Every button carries a leading single-colour icon.

Principles

  • One layout: a single centred column, 430 px max. On desktop the column is width-constrained with a hairline side border — no separate desktop layout.
  • Light mode only. No dark palette, no theme switch.
  • All UI copy in English.
  • Every <button> / button-styled link has a leading monochrome line icon. Exception: the Google-rendered Sign in with Google button (fixed by Google).
  • Components are hand-written on Tailwind v4 tokens; Radix primitives (Dialog, Label, Avatar) stay for behaviour. No shadcn/ui.

Colour

Revised for contrast (feedback round 1). The moss / wheat / parchment identity is kept, but every functional pair now clears WCAG AA. The discovery’s literal values (#6B8570, #EBD07A, #FAF7F0) are retained only as the direction; the tokens below are deeper.

--primary #48624Fmoss — primary fill, outline, focus ring. White on it ≈ 6.7:1 ✓AA
--secondary #E3C25Cwheat — accent only: badge, heading rule. Never a CTA.
--bg-1 #FFFFFFcards, inputs, sheets, dialogs
--bg-2 #F2EDE0page ground & desktop gutter — now clearly distinct from card white
--text #2A332Cnear-black moss — body + headings. On white ≈ 13:1 ✓AAA
--text-muted #5C6A5Fsecondary text, placeholder, footer. On white ≈ 5.7:1 ✓AA
--border #BDB5A0dividers, input border, card outline — visible at 1px now
--error #A9473Eerror text + destructive fill. On/against white ≈ 5.7:1 ✓AA
What changed & why. The first pass sat around 3–4:1 for buttons, muted text and borders — legible but flat. This pass darkens --primary (3.35 → 6.7:1 with white), --text-muted (3.9 → 5.7:1), --error (4.6 → 5.7:1), makes --border actually visible, and deepens --bg-2 so the single column and its cards separate without a shadow. Only the Google Sign-in button keeps its own (fixed) colours.

Typography

Two families. Chrome (headings, labels, buttons, nav, captions) is the rounded display face, self-hosted: Zen Maru Gothic → M PLUS Rounded 1c → system rounded. User content (input fields, group / item names, any typed text) uses whatever gothic the OS already ships — ui-rounded / Hiragino Maru Gothic on Apple, Yu Gothic UI / Meiryo on Windows, the system sans elsewhere — no web font is downloaded for it. Reason: the self-hosted rounded face gets hard to read in Japanese at body size, and a built-in rounded gothic is fine when the OS has one. Scale = 16 · φ with √φ half-steps. Body line-height = φ (1.618).
